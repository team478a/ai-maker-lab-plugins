Source Article Studio ダウンロード版

Pluginは無料です。利用にはCodexを使えるPC環境が必要で、Codex側の利用条件や契約が適用される場合があります。

Windows

  1. ZIPを右クリックし、「すべて展開」を選びます。
  2. 展開したフォルダのinstall-windows.cmdをダブルクリックします。
  3. 完了後にCodexを再起動します。

macOS / Linux

ターミナルで展開したフォルダへ移動し、sh install-macos-linux.shを実行します。

安全について

  • 管理者権限、APIキー、パスワードを要求しません。
  • noteへの投稿、予約、決済は行いません。
  • OSの警告を無理に回避せず、心配な場合はスクリプトをテキストで確認してください。

詳しい操作はdocs/JAPANESE_FREE_GUIDE.md、完成例はexamples/beginner-note/にあります。
