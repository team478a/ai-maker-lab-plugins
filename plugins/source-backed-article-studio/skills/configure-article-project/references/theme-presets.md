# Theme presets

Presets provide starting defaults, not fixed editorial rules. Explicit user choices override them.

## Side hustle

- Focus: a realistic problem, method, constraints, and verification steps
- Evidence: personal experience, confirmed product facts, and dated market observations
- Avoid: guaranteed income, invented demand, or effortless-success language

## How-to

- Focus: prerequisites, steps, expected result, failure cases, and limitations
- Evidence: completed procedure, official references, or reproducible observations
- Avoid: presenting an untested sequence as verified

## Development log

- Focus: purpose, implemented change, actual problem, test result, current limitations, and next step
- Evidence: commits, pull requests, code changes, and recorded test output
- Avoid: exposing private source code or calling planned work complete

## Product story

- Focus: user problem, design decision, current capability, limitations, and intended use
- Evidence: product source of truth and actual released behavior
- Avoid: fictional customers, testimonials, usage, or performance

## Custom

Use the user's structure. Still require an audience, objective, and source roles.
