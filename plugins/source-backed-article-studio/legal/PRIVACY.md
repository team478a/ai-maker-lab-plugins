# Privacy Policy

Last updated: 2026-11-14

This policy applies to Source Article Studio, a skills-only plugin distributed by AI MAKER LAB.

## Service structure

Source Article Studio is a skills-only plugin. AI MAKER LAB does not operate a plugin server, user account system, analytics service, advertising service, or payment system for this plugin.

The plugin provides instructions and templates that run within the user's ChatGPT or Codex environment. Processing performed by those host products is governed by the terms and privacy policies applicable to the user's account.

## Data categories

The workflow may process information the user chooses to provide for an article, including:

- article themes, audiences, channels, objectives, and writing preferences;
- source text, files, URLs, Git history, and personal experience records selected by the user;
- generated drafts, evidence manifests, and review checklists.

Users must not provide passwords, API keys, authentication tokens, government identifiers, payment-card data, protected health information, or other data that is unnecessary for article drafting.

## Purpose

Provided information is used only to configure an article project, distinguish source roles, draft Markdown content, record supporting evidence, and identify items requiring human review.

## Recipients and sharing

AI MAKER LAB does not independently receive article inputs or generated drafts through this skills-only package. The plugin does not automatically publish, upload, email, schedule, or transmit a draft to note, WordPress, or another external service.

If a user separately chooses a host-provided connector, browser action, or sharing feature, that action is outside this plugin's automatic behavior and is governed by the selected service and the user's instruction.

## Storage and retention

The plugin does not maintain developer-operated storage. Files created in a local workspace remain there until the user changes or deletes them. Retention within ChatGPT, Codex, connected services, backups, or organization-managed environments follows the policies and controls of those services.

## User controls

Users can choose which sources to register, mark sources as private, restrict private sources to exact `allowed_claims`, edit or delete local project files and drafts, and uninstall the plugin. Users should review every draft before sharing it externally.

## Changes and contact

Material changes to data handling will be reflected in this policy and its last-updated date before release.

Questions or reports can be submitted through the [AI MAKER LAB Plugins issue tracker](https://github.com/team478a/ai-maker-lab-plugins/issues). Do not include article drafts, private sources, credentials, personal information, or other confidential data in a public issue.
