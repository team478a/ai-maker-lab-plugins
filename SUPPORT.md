# Support

Questions and reproducible defect reports for AI MAKER LAB Plugins can be submitted through [GitHub Issues](https://github.com/team478a/ai-maker-lab-plugins/issues).

Before opening an issue:

- remove API keys, authentication tokens, personal information, private sources, and unpublished drafts;
- include the plugin name and version;
- describe the expected behavior, actual behavior, and minimal reproduction steps;
- confirm whether the issue occurs in ChatGPT, Codex desktop, or Codex CLI.

The public issue tracker is not an emergency or confidential support channel. Do not use it for legal notices or sensitive disclosures.
