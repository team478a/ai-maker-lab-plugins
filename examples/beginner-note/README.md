# 初心者向け記事下書きサンプル

Source Article Studioが扱う4種類の成果物を、公開して問題のない架空の題材で示します。このサンプルは操作結果の形式を説明するための固定例で、利用実績や効果を示すものではありません。

- [`project.json`](project.json): テーマ、読者、媒体、目的
- [`sources.json`](sources.json): 使用する資料と公開可否
- [`draft.md`](draft.md): 読者向けMarkdown下書き
- [`draft.manifest.json`](draft.manifest.json): 事実、根拠、確認項目、本文hash
- [`sources/article-workflow.md`](sources/article-workflow.md): サンプルの根拠資料

実際に使うときは、このファイルを直接編集するのではなく、日本語ガイドの依頼例から新しい記事プロジェクトを作ってください。
