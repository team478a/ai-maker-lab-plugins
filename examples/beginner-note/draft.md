# AIで記事を書く前に、根拠を3段階で整理する

> タイトル候補: AIで記事を書く前に、根拠を3段階で整理する / 初めての記事下書きで迷わないための準備 / 確認済みの情報から記事を組み立てる方法

AIで記事の下書きを作る前に、テーマと資料を整理しておくと、どこまで確認できているかを見直しやすくなります。このサンプルでは、準備を3段階に分けます。

## 1. テーマ、読者、目的を決める

最初に「何について」「誰に向けて」「読後に何を理解してほしいか」を決めます。文章を書き始める前に目的を一文にすると、途中で話題が広がりすぎるのを防ぎやすくなります。

## 2. 確認済みと未確認を分ける

記事に使いたい情報を並べ、確認できた内容と、まだ確認が必要な内容を分けます。未確認の内容は、空白を埋めるために推測せず、公開前の確認項目として残します。

## 3. 下書きと根拠一覧を確認する

読者向けの下書きと、事実ごとの根拠一覧を分けて用意します。最後に人が両方を見比べ、本文が資料の範囲を超えていないかを確認します。

この3段階は、文章を自動で正しくする保証ではありません。資料そのものの正確さ、引用、著作権、個人情報、掲載先の設定は、公開する人が確認します。

## 公開前に確認すること

- [ ] タイトルと見出しが記事の目的に合っている
- [ ] 未確認の内容を事実として書いていない
- [ ] 根拠一覧と本文が対応している
- [ ] 引用、著作権、個人情報、掲載設定を確認した
